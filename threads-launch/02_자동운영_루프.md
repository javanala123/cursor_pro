# 자동 운영 루프 — 사람은 하루 30분, 나머지는 에이전트

## 설계 원칙

윤자동 실험에서 사람이 한 일은 네 가지뿐이었다. 목표 부여, 품질 반려, 방향 수정, 사실 검증. 실행은 하나도 하지 않았다. 그대로 복제한다.

핵심은 **1시간마다 발행하고 5분마다 댓글에 답하는 것**인데, 이건 사람이 사흘도 못 버틴다. 여기가 유일한 레버리지 지점이다.

## 2. 댓글 응대 루프 (가장 중요)

```
매 5분:
  1. 신규 댓글 수집
  2. 각 댓글 분류
     - 질문형   → 실질적 답변. 원글보다 길게.
     - 반박형   → 반박하지 않고 데이터로 응답. 틀렸으면 인정.
     - 응원형   → 짧게 감사 + 되묻기 (대화 연장)
     - 스팸/광고 → 무시
  3. 답글 발행
  4. 반박형 중 날카로운 것은 별도 글 소재로 승격
```

**규칙**
- **답글은 원글보다 길게.** 댓글이 원글보다 길어지면 알고리즘이 "진짜 대화"로 판단해 도달을 넓힌다. 이게 스레드에서 가장 강한 단일 신호다.
- **모르면 모른다고 쓴다.** 아는 척하면 반박당하고, 반박당하면 신뢰가 끝난다.
- **부정 댓글을 지우지 않는다.** 논쟁은 답글 수를 늘리고, 답글 수가 도달이다.

## 3. 발행 트리거 (판매 자체가 콘텐츠)

| 조건 | 즉시 발행 |
| --- | --- |
| 첫 결제 | "첫 결제가 났습니다. [경과] 만입니다" |
| 누적 5·10·25·50건 | 숫자 + 유입 경로 분석 |
| **6시간 무판매** | 세일즈 중단 → **상담 글로 전환** |
| 가격 인상 D-3 | 인상 예고 |
| 날카로운 반박 등장 | 그 대화를 그대로 옮긴 글 |

`6시간 무판매 → 상담 전환`이 가장 중요한 트리거다. 윤자동이 정확히 이 지점에서 막혔고, 상담으로 바꾼 직후 알고리즘이 붙어 14만 9천 원짜리가 팔리기 시작했다.

## 4. 사람이 반드시 검증할 것 (위임 금지)

1. **숫자.** 조회수·매출을 부풀리면 그 순간 끝이다. 캡처 원본과 대조한다.
2. **환불·결제 표기.** 윤자동 사례에서 AI가 환불 정책을 잘못 써서 사람이 잡아냈다. 전자상거래 필수 표기는 규정 원문을 복사만 한다.
3. **없는 경력·없는 실적.** AI가 그럴듯하게 지어내면 반려한다. 이 실험은 "재료 없이 되는가"가 주제라 경력을 꾸미는 순간 자기부정이다.
4. **타인 저작물.** 인용은 출처를 밝힌다.

## 6. 지키는 선

- 계정 대량 생성·자동 팔로우·좋아요 봇은 쓰지 않는다. 며칠 만에 차단되고 손해는 계정 주인이 본다.
- 커뮤니티에 홍보글을 도배하지 않는다. 질문에 실제로 답하고 필요할 때만 링크한다.
- 광고성 정보 대량 전송은 수신 동의 요건과 야간 발송 제한이 있다. 스레드 발행은 여기 해당하지 않지만, 메일·문자로 확장할 때는 반드시 확인한다.
- 매출·조회수 숫자를 부풀리지 않는다. 0이면 0이라고 쓴다. 이 실험의 유일한 자산이 신뢰성이다.
