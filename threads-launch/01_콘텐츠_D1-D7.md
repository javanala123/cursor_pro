# 스레드 발행 원고 — D1~D7

## 공통 규칙 (모든 글에 강제 적용)

1. **첫 줄에 숫자 또는 의외성.** "안녕하세요 오늘은~"으로 시작하면 거의 다 묻힌다.
2. **시간순 서사** — 처음 → 변화 → 결과 순으로 쓴다.
3. **"그런데 의외였던 건"** 한 줄을 본문 후반에 반드시 넣는다. 200개 분석에서 저장률을 평균 4.3배 올린 문구다.
4. **질문으로 끝낸다.** 단, 아무 질문이 아니라 본문 내용과 직접 연결된 질문이어야 한다.
5. **본문에 링크 금지.** 발행 직후 **첫 댓글**에 링크를 단다. 본문 링크는 도달을 깎는다.
6. **하루 3개.** 08:30 / 12:30 / 20:30. 5개를 넘기지 않는다. 10개는 역효과다.
7. **해시태그 1~2개**만. 스레드는 해시태그 가중치가 거의 없고 많으면 깎인다.
8. **댓글이 달리면 5분 안에, 원글보다 길게 답한다.** 이게 도달 확대의 직접 신호다.
9. **발행 직후 30분은 남의 글에 답글을 단다.** 초기 참여를 만들어내는 유일한 수단이다.

# D4~D7 — 판매 중계 구간

여기서부터는 **모든 판매가 콘텐츠**다. 윤자동이 "방금 3권이 팔렸어", "50권 팔았다", "목표가 코앞이다"를 각각 글로 올린 것과 같다. 판매 자체가 발행 소재가 되므로 소재 고갈이 없다.

## 발행 트리거 (에이전트 자동 실행)

| 트리거 | 발행 내용 |
| --- | --- |
| 첫 판매 발생 | "첫 결제가 났습니다. [경과시간] 만입니다" + 그 순간의 감상 |
| 5·10·25·50건 돌파 | 누적 숫자 + 구매자 유입 경로 분석 |
| 6시간 무판매 | 세일즈 대신 **상담 글**로 전환 (윤자동의 티핑포인트 재현) |
| 매일 20:30 | 일일 숫자 전체 공개 (조회·팔로워·매출) |
| 가격 인상 3일 전 | 인상 예고 |
| 부정 댓글 발생 | 반박하지 않고 데이터로 답한 뒤 그 대화를 별도 글로 |

## 가격 인상 예고 (날짜 고정)

- D3: 1,000원 — 사례 정밀 분해
- D4~D6: 9,900원 — 알고리즘 지식 + 실행 설계 세트로 상품 교체
- D7~D13: 29,000원 — 실측 데이터가 붙는 첫 시점
- D14~: 49,000~99,000원

> 이전 판(D4/D6/D10/D15)을 압축했다. 2차 상품이 실측 데이터를 기다릴 이유가 없다는 판단 때문이다. 알고리즘 지식과 실행 설계는 내 성공 여부와 무관한 사실이므로 D4에 낼 수 있다. 근거는 `00_결정과_근거.md` 4-1 참조.
